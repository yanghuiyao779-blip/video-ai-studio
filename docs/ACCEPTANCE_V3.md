# v3 真实环境验收清单

以下不是已完成记录，而是部署后需要逐项执行的检查。

## 安装和回退
- [ ] 备份 PostgreSQL、app_data、环境密钥和 secrets。
- [ ] 在库副本执行 0008 → 0009，核对原 Job/Creator 数量及结果文件。
- [ ] 启动 API、媒体 Worker、Assistant Worker、reconciler、前端并检查日志。
- [ ] 保持原 Compose 项目名、管理员名和加密密钥，旧账号/模型配置可用。
- [ ] npm ci && npm test && npm run build 成功。
- [ ] 浏览器检查桌面、窄屏、移动菜单、中文输入法和键盘焦点。
- [ ] 在独立环境演练备份恢复，不仅依赖 downgrade。

## P0
- [ ] 普通问题 → 流式回答 → 追问 → 刷新 → 历史中再次打开。
- [ ] 生成中切换页面再返回，不创建重复消息或重复付费调用。
- [ ] 有权访问的 B 站/YouTube/抖音链接 → 预览 → 发送 → 真实阶段 → 摘要 → 追问。
- [ ] 分享文字附链接、短链接和多链接正确识别；账号主页/普通网页不误触发。
- [ ] 仅普通聊天、不要下载/解析的请求不创建下载任务。
- [ ] 上传真实音视频，检查上传进度、空文件/超限错误和失败提示。
- [ ] 询问 08:10 讲了什么，点击引用，对照文字稿。
- [ ] 模型异常保留部分消息，停止/重试不会重复下载视频。
- [ ] Worker/Redis 不可用时有真实等待或错误，不伪造完成。

## 检索和原功能回归
- [ ] 无 Embedding 时关键词检索可用。
- [ ] 1536 维模型、PostgreSQL 向量查询与 HNSW 表达式索引可用。
- [ ] 错误维度、429、超时导致检索降级，不删文字稿。
- [ ] 编辑文字稿后索引失效，新问答使用新内容。
- [ ] 原取消、重试、重新摘要、所有导出格式正常。
- [ ] 原博主同步、研究控制、画像和导出正常。
- [ ] 单独测试媒体 Worker 异常退出、长视频、CPU/GPU 及磁盘容量。

## P1
- [ ] 总结、会议纪要、笔记和脚本使用当前素材。
- [ ] 时间轴只引用存在的片段，非法 JSON 不伪装成成功图表。
- [ ] 思维导图为安全文本树，HTML/脚本不执行。
- [ ] 改名、置顶、归档、标签、搜索、分页和导出正常。
- [ ] 管理员从已有博主进入对话，不能假装读取尚未转写的内容。

## P2 权限
- [ ] 管理员、Alice、Bob 的私有视频/聊天互不可见。
- [ ] viewer 只读，editor 可继续项目对话，owner 可管理成员。
- [ ] 传入他人未共享视频 ID 时被拒绝。
- [ ] 撤销项目成员后，其创建的项目会话也不可访问。
- [ ] 借用的视频撤权后，不再通过旧私有会话暴露新的实时元数据。
- [ ] 普通用户不借用部署管理员的平台 Cookie/登录态。
- [ ] 分享默认无引用原文，新消息不自动公开，到期或撤销后不可访问。
- [ ] 删除会话/项目不删除源视频；在副本验证删除原视频的级联影响。

## P2 外部能力
- [ ] 未配置时联网/视觉入口明确不可用。
- [ ] Tavily 仅发送当前搜索问题，不发送完整文字稿；用户明确允许。
- [ ] 新视频抽帧数量受限，视觉请求获用户允许后才发给模型。
- [ ] 旧任务无帧时明确提示，不编造已看过画面。
- [ ] Agent 的未知工具/超出步数被拒绝或限制。
- [ ] 学习包第二步失败保留第一步，重试可复用；文字稿改变后不复用旧结果。

## 上线条件
- [ ] HTTPS、SSE buffering、上传大小、代理超时正确。
- [ ] CPU/内存、并发数、上下文和模型费用符合实际机器容量。
- [ ] 下载 Worker 网络出口受控，不能仅依赖 URL 预检隔离内网。
- [ ] 向不可信用户开放前补齐限流、账号生命周期、费用配额和审计。
