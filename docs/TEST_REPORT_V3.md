### 测试性质

后端助手测试使用真实 FastAPI、认证与权限代码、SQLAlchemy、隔离的 SQLite、实际文件存储与成果导出。**模型和 HTTP 服务使用明确的测试替身或 MockTransport**，不代表验证了任何真实模型的输出质量、成本、时延或供应商兼容性。

上传测试验证接收、存储、归属和会话挂载，不把测试字节送入 ASR。媒体 API 测试验证原任务读写权限、文字稿编辑、索引失效及导出，不代表完整视频处理链路已实测。

前端测试运行在 Node 中，覆盖纯函数与网络流解析。TypeScript `transpileModule` 用于 JS/JSX 语法检查；**不等同 npm run build、React 运行时、浏览器或端到端测试**。

## 新测试覆盖

`backend/tests/assistant/`：

- 登录与接口鉴权、普通账号不能读取全局 Key/存储管理。
- 多轮消息落库、重复请求幂等、会话运行冲突、流式快照重读。
- 普通模式和普通网页不创建下载；视频链接只创建一份任务并等待结果。
- 视频素材归属、跨用户 ID 注入、项目 viewer/editor、成员撤权。
- 撤权后旧私有会话不能读取新的视频元数据，仍可移除失效引用。
- 上传归属、空文件/不支持格式、旧视频接口权限回归。
- 文字稿编辑重新导出、清除旧摘要、使问答索引失效。
- 不允许处理中的视频被并发编辑文字稿。
- 中文词法检索、时间点查询、取材范围、文字稿版本变化。
- Embedding 顺序、维度、批次、失败降级、旧版本结果不得覆盖新索引。
- 停止、部分输出保存、显式重试、重复 Worker 投递不重生成。
- 学习包按步保存，中途失败后的步骤复用和成果 ZIP。
- 过期运行恢复为失败，不自动重放已失败的付费模型请求。
- 分享快照不可变、默认不附原文、期限和撤销。
- 搜索只发送问题、来源协议筛选、工具白名单。
- 流式 UTF-8/隐藏推理字段/异常结束/非流式兼容响应。
- 结构化时间轴引用校验、概念树深度和节点上限。
- 真实 FFmpeg/FFprobe 抽帧数量与文件检查。
- 普通账号预览/下载配置不继承管理员的 Cookie/浏览器登录态。
- 新 PostgreSQL 迁移的离线 SQL 生成，以及旧无归属 Job 的管理员接管。

## 为什么仍需真实环境验收

此环境没有 Docker、PostgreSQL、Redis 服务和 Celery/Whisper/yt-dlp 等完整运行依赖，且 npm 下载不可用。即使所有上述离线测试通过，也不能据此证明以下事项：

- Docker 镜像构建、旧数据库真实升级、pgvector 执行计划正确；
- 所有真实 OpenAI-Compatible 供应商均遵循同样的 SSE/图片接口格式；
- 当前 B 站/抖音/YouTube 的鉴权和风控下可成功处理特定视频；
- React 页面像设计图一样显示、手机交互和大数据量渲染正常；
- 多 Worker 并发、异常重启、费用和资源容量符合生产要求。
